### US-002: Instance-state sampler background loop — done
- app/services/state_sampler.py: StateSampler (start/stop via create_task + cancel/await,
  sleep via asyncio.Event wait_for timeout) and state_sampler singleton; started and
  stopped in the app/main.py lifespan next to the reconciler.
- Each tick reads RegistryStore.get_registry and the host resource snapshot per host
  (once per host per tick); one StateSample per registry entry, alias = registry key.
  State: "running" when the snapshot age (entry_age_s) <= host_snapshot_max_age_s,
  otherwise "offline" (missing/malformed/unreadable snapshot never raises).
- Multi-replica: a Redis NX lock (solar:state_sampler:lock, 0.9 x interval) so only one
  replica writes per interval; a failing tick is logged and the loop continues.
- Settings.state_sample_interval_s (default 30s) in app/config.py.
- Tests: tests/test_state_sampler.py (row per instance, state values, empty registry,
  stale/missing snapshots, lock, loop survives errors and stops).

### US-005: Automatic message visibility window — done
- GET /api/status carries a single `messages` list: messages with start_time <= now < end_time
  (no end_time = open-ended), plus planned maintenance whose start_time is still ahead.
  Every other type is hidden until its window opens; ended messages of every type are dropped.
  No publish state: visibility derives only from start_time/end_time.
- Upcoming vs active is NOT a server concept: each message carries type and start_time, so
  the client compares start_time with the response's generated_at (US-007).
- visible_messages() in services/status_summary.py is the single place that applies the
  rules; StatusMessageDB.list_not_ended(now) pre-filters ended rows in SQL. Messages are read
  live on every request (not cached) so windows open/close exactly on time.
- Tests: tests/test_status_summary.py (start inclusive / end exclusive boundary, past end,
  open-ended, future start per type, order), tests/test_status_route.py (public response,
  future maintenance hidden, planned maintenance published ahead, empty).
- make test-solar-control and make lint-solar-control pass.
