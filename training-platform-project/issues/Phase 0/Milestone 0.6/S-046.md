# S-046: Fix nested-path digest verification after a Harbor pull

## Description

`_verify_pulled_digests` in `solar_host/models_manager.py` checks every pulled file's sha256 against the OCI manifest layer digests. It builds the expected map from the `org.opencontainers.image.title` annotations, which may contain a relative path such as `nested/extra.txt`, but it collects the actual map by iterating `target_dir.iterdir()` non-recursively and keying on `path.name`.

Any artifact containing a subdirectory therefore fails: the nested title never appears in the actual map, and the function raises `ModelPullError(502, "model_pull_failed", "... nested/extra.txt: missing on disk after pull")`. This was verified against the live registry — `oras` restores the nested file correctly, and verification rejects it anyway.

There is also a latent path-traversal hole: a title such as `../../etc/passwd` would be compared against a file written outside `target_dir` rather than being rejected.

This becomes load-bearing once artifacts can be uploaded from arbitrary folders (S-047, U-007), where nested directories are common in HuggingFace-format repositories.

## Goal

- Make `_verify_pulled_digests` walk the pull target recursively and key the actual map on the path relative to `target_dir`, POSIX-separated, so it matches the manifest titles.
- Reject manifest titles that are absolute or contain `.` / `..` segments before comparing, raising `ModelPullError` rather than silently verifying a file outside the target directory.
- Leave `_verify_cached_digests` as is — it already indexes `base / name`, which resolves nested names correctly — but add a regression test covering the nested case.
- Note in the docstring that `file_digests` keys are now relative paths. Manifest entries written before this change hold bare filenames, which are identical to relative paths for flat artifacts, so no migration is required.
- Add regression tests: nested verification passes, flat verification is unchanged, a corrupted nested file is detected, a deleted nested file is detected, and a traversal title is rejected.
- Run `make test-solar-host` and `make lint-solar-host`.
