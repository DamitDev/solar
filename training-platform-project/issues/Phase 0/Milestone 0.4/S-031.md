# S-031: Build `supernova-step-convert-model` image

## Description

SuperNova pipelines need a conversion step image for turning HuggingFace-format model outputs into GGUF artifacts suitable for llama.cpp-based inference. The conversion step reads from the shared job workspace and writes converted outputs back to that same workspace for later upload.

The converter image should treat its input as files produced by earlier opaque steps and should not depend on Etalon internals.

## Goal

- Build a Docker image named `supernova-step-convert-model` in the `supernova-steps` repo.
- Accept input path, output path, conversion format, and quantization parameters.
- Include or install the required llama.cpp conversion tooling in the image.
- Validate all input/output paths stay under `/workspace`.
- Emit clear logs for conversion start, selected parameters, output files, and failures.
- Provide a minimal README or usage example and a local smoke test with a small compatible model where practical.

### S-021 Workspace Reference

The `/mnt/nvme/AI/damit-aiops/solar/training-platform-project/docs/specs/job-step-workspace.md` defines the full contract. Key points for this step:

- **Environment input:** `MODEL_INPUT` (HF model directory, e.g. `/workspace/output/base_osl/best`), `MODEL_OUTPUT` (GGUF file path, e.g. `/workspace/output/base_osl.gguf`), `QUANTIZATION` (e.g. `Q4_K_M`), plus all workspace paths (Section 4.1) and infrastructure credentials (Section 4.2).
- **Reading previous step results:** Read `job.json` → `steps.train.best_checkpoint_path` for the HF model to convert. The train step writes this; the convert step consumes it.
- **Conversion:** Use llama.cpp conversion tooling to convert HF model at `MODEL_INPUT` to GGUF at `MODEL_OUTPUT` with the specified `QUANTIZATION` level.
- **Write to config:** After conversion, update `job.json` → `steps.convert_model` with `output_path`, `quantization`, `input_path`. The upload step (S-030) reads this if conversion is in the pipeline.
- **Path safety:** Validate that both `MODEL_INPUT` and `MODEL_OUTPUT` are under `/workspace/`.
- **Exit code:** 0 on success, non-zero on conversion failure.
