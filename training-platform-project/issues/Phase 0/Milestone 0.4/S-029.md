# S-029: Build `supernova-step-download-dataset` image

## Description

SuperNova training pipelines need a step image that resolves a dataset artifact through the Data Repository and pulls dataset files directly from Harbor into the shared job workspace. The Data Repository supplies metadata and the `harbor_ref`; the image performs ORAS transfer with `harbor-oci-client`.

The image writes to the ephemeral job workspace only and must not use Solar Host's managed inference model cache.

## Goal

- Build a Docker image named `supernova-step-download-dataset` in the `supernova-steps` repo.
- Accept dataset source URI and output path arguments, for example `repo://iris-tickets:2026-03` and `/workspace/data/train`.
- Resolve the dataset through Data Repository, using D-014 or dataset version detail data from D-010 as appropriate.
- Pull the returned `harbor_ref` directly from Harbor with `harbor-oci-client` / ORAS into the requested workspace path.
- Validate destination paths stay under `/workspace` and fail clearly for missing URI, missing artifact, auth failure, or ORAS pull failure.
- Provide a minimal README or usage example and a local smoke test command.

## Additional Notes

- Repo: `supernova-steps` at `/mnt/nvme/AI/damit-aiops/solar/apps/supernova-steps`
- Key files likely: new image directory, Dockerfile, Python entrypoint, dependency manifest, README.
- Depends on D-014 (URI resolution endpoint) and D-010 (dataset version detail endpoint).
- Consumed by S-023/S-027 job execution and future SuperNova training job templates.

### S-021 Workspace Reference

The `/mnt/nvme/AI/damit-aiops/solar/training-platform-project/docs/specs/job-step-workspace.md` defines the full contract. Key points for this step:

- **Environment input:** `DATASET_URI` (e.g. `repo://iris-tickets:2026-03`), `DATASET_OUTPUT_DIR` (e.g. `/workspace/data/tickets-dataset`), plus all workspace paths (Section 4.1) and infrastructure credentials (Section 4.2).
- **Resolution:** Resolve `DATASET_URI` via Data Repository `GET /api/resolve?uri=...` to get the `harbor_ref`.
- **Pull:** Use `harbor-oci-client` / ORAS to pull the artifact from Harbor into `DATASET_OUTPUT_DIR`.
- **Write to config:** After successful pull, update `job.json` → `steps.download_dataset` with `dataset_dir`, `source_uri`, `harbor_ref`, `record_count`, `format`.
- **Path safety:** Validate that `DATASET_OUTPUT_DIR` is under `/workspace/data/`. Fail with clear error if not.
- **Exit code:** 0 on success, non-zero on any failure.
