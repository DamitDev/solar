# S-060: Virtual models — stable aliases with context/capability contracts

## Description

Upstream applications (Cursor, ai-wiki, orchestrator agents, CI harnesses) currently
address solar by real registry alias (`deepseek-v4-flash:284b`,
`qwen3.8-flash-next:180b`). Whenever the served model changes, every client must be
reconfigured, and clients silently inherit whatever context window and capabilities
the currently-served model happens to have — a 1M-context model replaced by a 262K
one silently truncates or 400s long prompts.

Virtual models are persistent, editable aliases on solar-control: a virtual model has
a fixed public name, an ordered target list of real registry aliases, and a declared
contract (minimum context size, required capabilities). Routing resolves the virtual
name to the first target that has a healthy instance satisfying the contract; if a
target is undeployed or violates the contract the next target is tried, so the
declared contract always holds for callers. The `/v1/models` listing gains a
synthetic entry per virtual model advertising the declared contract.

## Goal

- New `virtual_models` table (alembic 0010) + management API
  (`GET/POST /api/virtual-models`, `PUT/DELETE /api/virtual-models/{name}`) mirroring
  the intents vertical.
- Contract enforcement at routing time: targets that cannot satisfy the declared
  `context_size` / `capabilities` are skipped (reason recorded); exhaustion yields a
  503 naming each target's state.
- Save-time validation: name format/uniqueness, bidirectional shadow check against
  live registry aliases (exact or prefix collision), hard 422 when an existing target
  violates the contract, 201-with-warnings when a target does not exist (yet).
- `/v1/models` synthetic entries (`owned_by: "solar-virtual"`) filtered by endpoint
  `model_patterns` like real aliases.
- Webui "Virtual Models" page: list with ordered target chips colored by live target
  status (satisfied / violating / missing), create/edit modal with reorderable
  targets and contract fields, delete.
