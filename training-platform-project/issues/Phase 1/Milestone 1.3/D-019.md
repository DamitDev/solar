# D-019: Add artifact-level delete to the Data Repository

## Description

The Data Repository can unregister a single version (`DELETE /api/models/{name}/versions/{version}`), but there is no way to remove an artifact entirely. Because `list_artifacts_by_category` outer-joins the version-count subquery (`app/repositories/artifacts.py`), deleting every version of an artifact leaves a ghost catalog entry with `versions_count: 0` — the artifact row survives and keeps appearing in listings. An artifact-level delete endpoint is required.

The deletion is an unregister operation only: the Data Repository stays a pure registry. Harbor blob deletion is orchestrated by Solar Control (S-048), which deletes the Harbor artifacts first and then calls these endpoints — mirroring the upload relay direction (Solar Control writes to Harbor, Data Repository registers metadata).

## Goal

- Add `_delete_artifact(name, category, not_found_exc)` to `ArtifactRepository` (`app/repositories/artifacts.py`), mirroring the existing `_delete_artifact_version`: a single `delete(Artifact).where(name, category)`, `rowcount == 0` → not-found via the existing disambiguation. Version rows disappear through the existing `ON DELETE CASCADE`.
- Add `delete_model(name)` / `delete_dataset(name)` wrappers.
- Add `delete_model(name)` / `delete_dataset(name)` to `ModelDeletionService` / `DatasetDeletionService` (`app/services/models.py`), reusing `_validate_artifact_name` and the existing `_commit()` (the `get_db_session` teardown commit races the next request — mutations must be durable before the response is returned).
- Add `DELETE /api/models/{name}` and `DELETE /api/datasets/{name}` routes (`app/routes/models.py`, `app/routes/datasets.py`) → 204, mapping `InvalidArtifactNameError` → 422 and `ModelNotFoundError`/`DatasetNotFoundError` → 404, matching the neighbouring version-delete route.
- Update the `_delete_artifact_version` docstring and `docs/schema.md`: Harbor deletion is no longer "deferred to N-029" — it happens in Solar Control's relay (S-048).
