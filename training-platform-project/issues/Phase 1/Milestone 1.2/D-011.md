# D-011: Implement metadata CRUD

## Description

Artifacts have metadata beyond the blob: category, description, training config, eval metrics, lineage (source trainer, source dataset, parent model). This metadata is used for search, browsing, and display in SuperNova WebUI. D-007/D-009 store initial metadata on registration; this issue adds full CRUD for updating metadata after the fact.

## Goal

- Implement `GET /api/models/{name}` – return artifact metadata (category, description, training_config, eval_metrics, lineage, created_at, versions count).
- Implement `PUT /api/models/{name}` – update metadata. Body: `description`, `training_config`, `eval_metrics`, `lineage`. Only updates Postgres metadata; does not affect Harbor blobs.
- Same for datasets: `GET /api/datasets/{name}`, `PUT /api/datasets/{name}`.
- Lineage fields: `source_trainer`, `source_dataset`, `parent_model` (artifact refs). Store as JSONB or structured columns.
- Return 404 if artifact does not exist. Artifact records are created on first registration (D-007/D-009); this CRUD updates existing records.
