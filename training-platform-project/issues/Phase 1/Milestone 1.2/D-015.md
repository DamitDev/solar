# D-015: Deploy Data Repository to aiops-k8s

## Description

The Data Repository runs as a Kubernetes deployment. D-004 provides a basic Dockerfile and Helm chart. This issue finalizes the Helm chart, creates the ArgoCD application, and configures environment values for dev and UAT. The service must be reachable by Solar Control, SuperNova Control, and step containers (for metadata/resolve queries).

## Goal

- Create or finalize Helm chart in data-repository repo (or in aiops-k8s). Chart: Deployment, Service, ConfigMap, Secret, Ingress (if needed).
- Should pull up its own postgres database, but a small one. 1Gi PVC both for dev and prod.
- ConfigMap: `DATABASE_URL`, `HARBOR_URL`. Secret: `HARBOR_USERNAME`, `HARBOR_PASSWORD` (or robot account token) — used by the Harbor API client for artifact verification (D-006).
- Environment values: Different DB URLs, Harbor credentials per env.
- ArgoCD Application: add `data-repository` to the app-of-apps or create standalone Application. Target namespace: `solar-dev` (dev), `solar` (prod).
- KEMP and DNS already configured for:
  - https://datarepo.damit.cloud/ - prod (on solar namespace)
  - https://datarepo-dev.damit.cloud/ - dev (on solar-dev namespace)
  - Make sure it is properly ingressed
