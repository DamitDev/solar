# D-013: Implement search and browse endpoints

## Description

SuperNova WebUI and operators need to discover models and datasets: list all, filter by category, search by name or metadata. The Data Repository must support list and search with pagination.

## Goal

- Implement `GET /api/models`. Query params: `search` (name/description), `limit`, `offset` (or `page`, `page_size`). Return list of artifacts with `category=model` and summary metadata. Equivalent to `GET /api/artifacts?category=model`.
- Implement `GET /api/datasets`. Same pattern, filtered to `category=dataset`.
- Optionally implement `GET /api/artifacts` with `category` filter for a unified endpoint.
- Pagination: return `total` count and `items` array. Default limit (e.g. 50).
- Search: use PostgreSQL `ILIKE` on name/description or JSONB `@>` for metadata fields. Add GIN index on metadata if needed.
- Response shape: `{"total": 42, "items": [{"name": "...", "category": "model", "description": "...", "versions_count": 3, "latest_version": "v3", "created_at": "..."}]}`.
