# D-010: Implement dataset version detail endpoint

## Description

Clients (SuperNova step containers) need to look up a specific dataset version to get its harbor_ref for direct ORAS pull from Harbor. This endpoint returns the metadata and harbor_ref for a given dataset name and version. It does NOT stream blob data — clients pull directly from Harbor.

## Goal

- Implement `GET /api/datasets/{name}/versions/{version}`. Same pattern as D-008 (model version detail).
- Return JSON with `harbor_ref`, metadata, `size_bytes`, `checksum`, `created_at`.
- Support `version=latest`.
- Return 404 if not found.

## Additional Notes

- Repo: `data-repository` at `/mnt/nvme/AI/damit-aiops/solar/apps/data-repository`
- Depends on D-005 (schema).
- S-029 (download-dataset step) resolves via Data Repository, then pulls directly from Harbor using the returned harbor_ref.
