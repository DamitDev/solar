# D-008: Implement model version detail endpoint

## Description

Clients (Solar Control, SuperNova step containers) need to look up a specific model version to get its harbor_ref for direct ORAS pull from Harbor. This endpoint returns the metadata and harbor_ref for a given model name and version. It does NOT stream blob data — clients use the returned harbor_ref to pull directly from Harbor.

## Goal

- Implement `GET /api/models/{name}/versions/{version}`. Path params: `name`, `version` (or `latest` alias).
- Return JSON: `{"name": "iris-osl", "version": "v3", "category": "model", "harbor_ref": "imgrepo.damit.hu/supernova/iris-osl:v3", "size_bytes": ..., "checksum": "...", "created_at": "...", "metadata": {...}}`.
- Support `version=latest`: resolve to most recent version by `created_at`.
- Return 404 if model or version not found.
