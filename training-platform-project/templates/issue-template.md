This is the basic template for generic issues in AIOps project management.

Formatting:
```
# Title of the issue

## Description
<small context of the issue, what's the current state of the program, how it is solving the issue currently, and why is it needed to be changed>

## Goal
<The result, or goal to achieve with the solution, often in lists to indicate logical structure in implementation. If this is a large change, then the titles of the sub-issues>

<optional> ## Additional Notes
<If this issue is referencing other repos, small context can go here about it. for example if this is a webui issue, and it connects to an api, describe here where it can find the correct docs/references to them>
```
