# S-028: Build `supernova-step-download-model` image

## Description

SuperNova training pipelines need a step image that resolves a model artifact through the Data Repository and pulls the model files directly from Harbor into the shared job workspace. The Data Repository is the metadata and resolve authority; Harbor stores blobs; the step image performs ORAS transfer using `harbor-oci-client`.

This image must not write into Solar Host's managed inference `MODELS_DIR` cache. It writes only to the ephemeral job workspace mounted by Solar Host.

## Goal

- Build a Docker image named `supernova-step-download-model` in the `supernova-steps` repo.
- Accept model source URI and output path arguments, for example `repo://iris-osl:v3` and `/workspace/models/base`.
- Resolve the model through Data Repository, using D-014 or model version detail data from D-008 as appropriate.
- Pull the returned `harbor_ref` directly from Harbor with `harbor-oci-client` / ORAS into the requested workspace path.
- Validate destination paths stay under `/workspace` and fail clearly for missing URI, missing artifact, auth failure, or ORAS pull failure.
- Provide a minimal README or usage example and a local smoke test command.
