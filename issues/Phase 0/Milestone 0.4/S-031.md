# S-031: Build `supernova-step-convert-model` image

## Description

SuperNova pipelines need a conversion step image for turning HuggingFace-format model outputs into GGUF artifacts suitable for llama.cpp-based inference. The conversion step reads from the shared job workspace and writes converted outputs back to that same workspace for later upload.

The converter image should treat its input as files produced by earlier opaque steps and should not depend on Etalon internals.

## Goal

- Build a Docker image named `supernova-step-convert-model` in the `supernova-steps` repo.
- Accept input path, output path, conversion format, and quantization parameters.
- Include or install the required llama.cpp conversion tooling in the image.
- Validate all input/output paths stay under `/workspace`.
- Emit clear logs for conversion start, selected parameters, output files, and failures.
- Provide a minimal README or usage example and a local smoke test with a small compatible model where practical.
