# D-014: Implement URI resolution endpoint

## Description

Solar Control's `repo://` resolver (S-013 stub, D-016 complete) needs to resolve URIs like `repo://iris-osl:v3` to artifact metadata and a harbor_ref for direct ORAS pull. The Data Repository is the authority for `repo://` URIs. This endpoint enables the resolver (and other consumers) to look up an artifact by its URI and get everything needed to pull it from Harbor.

## Goal

- Implement `GET /api/resolve?uri=repo://iris-osl:v3`. Parse the URI to extract artifact name and version.
- Return JSON: `{"category": "model", "name": "iris-osl", "version": "v3", "harbor_ref": "imgrepo.damit.hu/supernova/iris-osl:v3", "size_bytes": ..., "checksum": "...", "metadata": {...}}`.
- `harbor_ref` is the full OCI reference that clients use for direct ORAS pull from Harbor.
- URI format: `repo://{name}:{version}` (e.g. `repo://iris-osl:v3`, `repo://iris-tickets:2026-03`). Version is required; use `latest` for most recent.
- Return 404 if artifact or version not found.
- This endpoint is used by Solar Control's repo resolver (D-016) and by SuperNova job validation (N-004 verifies repo URIs exist before job submission).
