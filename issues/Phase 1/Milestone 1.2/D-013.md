# D-013: Implement search and browse endpoints

## Description

SuperNova WebUI and operators need to discover models and datasets: list all, filter by type, search by name or metadata. The Data Repository must support list and search with pagination.

## Goal

- Implement `GET /api/models`. Query params: `search` (name/description), `type` (if multiple model types), `limit`, `offset` (or `page`, `page_size`). Return list of artifacts with summary metadata.
- Implement `GET /api/datasets`. Same pattern.
- Pagination: return `total` count and `items` array. Default limit (e.g. 50).
- Search: use PostgreSQL `ILIKE` on name/description or JSONB `@>` for metadata fields. Add GIN index on metadata if needed.
- Response shape: `{"total": 42, "items": [{"name": "...", "type": "...", "description": "...", "versions_count": 3, "created_at": "..."}]}`.

## Additional Notes

- Repo: `data-repository` at `/mnt/nvme/AI/damit-aiops/data-repository`
- Depends on D-005 (schema, indexes).
- D-018 (catalog proxy) uses this. SuperNova WebUI model/dataset browsers use it.
