# D-015: Deploy Data Repository to aiops-k8s

## Description

The Data Repository runs as a Kubernetes deployment. D-004 provides a basic Dockerfile and Helm chart. This issue finalizes the Helm chart, creates the ArgoCD application, and configures environment values for dev and UAT. The service must be reachable by Solar Control, SuperNova Control, and SuperNova WebUI.

## Goal

- Create or finalize Helm chart in data-repository repo (or in aiops-k8s). Chart: Deployment, Service, ConfigMap, Secret, Ingress (if needed).
- ConfigMap: `DATABASE_URL`, `HARBOR_URL`, base URL for download links. Secret: `HARBOR_USERNAME`, `HARBOR_PASSWORD` (or robot account token).
- Environment values: `environments/dev/values/data-repository.yaml`, `environments/uat/values/data-repository.yaml`. Different DB URLs, Harbor credentials per env.
- ArgoCD Application: add `data-repository` to the app-of-apps or create standalone Application. Target namespace: `aiops-dev` (dev), `aiops-uat` (uat).
- Ensure the service is exposed: ClusterIP or Ingress. Solar Control and SuperNova need to reach `http://data-repository.aiops-dev.svc` (or similar).
- Document deployment, rollback, and config in README or runbook.
