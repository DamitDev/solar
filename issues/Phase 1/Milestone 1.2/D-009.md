# D-009: Implement dataset upload endpoint

## Description

Training datasets (Parquet, HDF5, JSON) are stored in the Data Repository alongside models. The upload flow mirrors model upload: stream → ORAS push to Harbor → metadata in Postgres. Uses `supernova/datasets` repository and dataset-specific media type.

## Goal

- Implement `POST /api/datasets/{name}/versions`. Same pattern as D-007 (model upload).
- Target: `imgrepo.damit.hu/supernova/datasets/{name}:{version}`. Media type: `application/vnd.supernova.dataset.v1`.
- Flow: (1) Receive stream. (2) Write to temp. (3) ORAS push. (4) Create `artifacts` (type=dataset) and `artifact_versions` rows. (5) Return version ID.
- Metadata: `size_bytes`, `checksum`, optional `description`, `format` (parquet, hdf5, json).
- Reuse ORAS layer and schema patterns from D-007. Factor shared logic if possible (e.g. generic `upload_artifact`).

## Additional Notes

- Repo: `data-repository` at `/mnt/nvme/AI/damit-aiops/data-repository`
- Depends on D-006 (ORAS layer).
- D-010 (dataset download) mirrors D-008. SuperNova step `download_dataset` uses this.
