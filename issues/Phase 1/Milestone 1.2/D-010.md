# D-010: Implement dataset download endpoint

## Description

Training jobs need to pull datasets from the Data Repository. The flow mirrors model download: resolve name+version → ORAS pull → stream to client. SuperNova step containers (e.g. `supernova-step-download-dataset`) will call this.

## Goal

- Implement `GET /api/datasets/{name}/versions/{version}/download`. Same pattern as D-008.
- Flow: (1) Resolve to `artifact_versions` (type=dataset). (2) ORAS pull. (3) Stream to client.
- Support `version=latest`.
- Return 404 if not found.
- Streaming response. Optional `Range` support.

## Additional Notes

- Repo: `data-repository` at `/mnt/nvme/AI/damit-aiops/data-repository`
- Depends on D-006 (ORAS layer).
- S-029 (download-dataset step) and SuperNova job steps use this.
