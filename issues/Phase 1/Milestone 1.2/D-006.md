# D-006: Implement Harbor API integration layer

## Description

The Data Repository does not proxy blob data — consumers push/pull directly to/from Harbor via ORAS. However, the Data Repository needs to interact with Harbor's REST API for artifact verification (confirming that a harbor_ref actually exists before accepting a registration) and artifact management (deletion for retention cleanup).

D-003 validated ORAS push/pull patterns. This issue implements the Harbor-facing module within the Data Repository for verification and management. Custom OCI media types are defined here for consistency across the ecosystem.

## Goal

- Create `app/harbor/` module with:
  - **`HarborClient`**: wrapper around Harbor's REST API. Config: Harbor URL, credentials (from env/secret).
  - **`verify_artifact(harbor_ref)`**: HEAD request (or equivalent API call) to Harbor to confirm that the referenced OCI artifact exists. Used by registration endpoints (D-007, D-009) to validate before accepting metadata.
  - **`delete_artifact(harbor_ref)`**: Delete an artifact from Harbor. Used by retention cleanup (N-029).
  - **`get_artifact_info(harbor_ref)`**: Optional — retrieve artifact metadata from Harbor (size, digest, media type) for cross-validation.
  - **Authentication**: Login/token management for Harbor API. Handle token expiry, retries.
  - **Error handling**: Registry unreachable, auth failure, 404, etc. Raise typed exceptions for API layer to map to HTTP status.
- Define custom OCI media types: `application/vnd.supernova.model.v1`, `application/vnd.supernova.dataset.v1`. Document for consumers (step containers) to use when pushing via ORAS.
- Document the module API for D-007/D-009 implementers.

## Additional Notes

- Repo: `data-repository` at `/mnt/nvme/AI/damit-aiops/data-repository`
- Depends on D-003 (ORAS POC findings, Harbor API patterns).
- D-007, D-009 use `verify_artifact()` during registration. N-029 uses `delete_artifact()` for retention.
- ORAS push/pull is NOT in this module — that responsibility belongs to the consumers (step containers S-028/S-029/S-030, Solar Control D-016).
